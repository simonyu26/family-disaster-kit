# 策略目標 v1（暫定版）

更新：2026-11-16｜決定人：擁有者

## 1. 最高原則
災難發生時確保生命安全。

## 2. 三條界線
1. 不在沒有資料時顯示「安全」。
2. 不取代政府警報與官方名冊。
3. 不未經同意收集或分享家人個資（未成年成員除外，家長或監護人可查看）。

## 3. 反指標
1. 開啟緊急模式到能按報案鍵的秒數變長。
2. 整體遊戲化元素的比例變高。
3. 與防災、備災、救災無關的新功能，數量多於相關功能時提出警示；累計總量不可超過相關功能。

## 4. 主線與優先順序
1. 會誤導或危及安全的錯誤（可在任何時段立即發布）
2. 資安與個資
3. 緊急模式與應變計畫
4. 平時物資與演練
5. 其他

## 5. 隱私與分享預設
- 全部只存本機；健康資料另外勾選才同步。
- 成年成員：分享給家人需本人同意。
- 未成年成員：家長（監護人）可以查看。
- 位置只在使用者按下時取用，不在背景追蹤。

## 6. 用語與風格
- 台灣繁體中文。
- 平時溫暖、不製造焦慮；緊急時簡短直接。
- 不用戰爭、末日等嚇人字眼。
- 公開 repo 與畫面不出現真實人名。
